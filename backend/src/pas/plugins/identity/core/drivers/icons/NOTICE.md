# Default driver icons

The login-button icon each shipped driver falls back to. Every file is copied
unchanged from the project below it, and the package sanitizes each one the
first time it is read, exactly as it sanitizes an uploaded icon.

| File | Copied from |
|---|---|
| `github.svg` | volto-authomatic, `packages/volto-authomatic/src/icons/github.svg` |
| `google.svg` | volto-authomatic, `packages/volto-authomatic/src/icons/google.svg` |
| `oidc-generic.svg` | volto-authomatic, `packages/volto-authomatic/src/icons/openid.svg` |
| `plone-identity.svg` | Volto, `packages/volto/src/icons/plone.svg` |
| `email.svg` | Volto, `packages/volto/src/icons/email.svg` |
