# Install and upgrade

Get the package running on a site, and keep it current.

| Guide | Does |
|---|---|
| {doc}`backend` | Installs the Python package and applies its profile |
| {doc}`frontend` | Adds the Volto add-on to your frontend |
| {doc}`upgrade` | Moves an existing site to a new release |

Install the backend first, then the frontend. Then add a provider: see
{doc}`/how-to-guides/providers/index`.
